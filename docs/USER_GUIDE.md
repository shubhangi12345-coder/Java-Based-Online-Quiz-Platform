# User guide

## Admin
1. Log in with the admin account from your `application-local.properties`.
2. **Users**: change a registered user's role to *Quiz Creator* (they must log in again), or disable an account.
3. **Dashboard / Quizzes**: open a quiz that is *Pending approval*, read the questions (correct answers are marked) and
   click **Approve**, or write a reason and **Reject**.
4. **Settings**: switch public registration on or off; set the default passing percentage.

## Quiz Creator
1. **New quiz**: title, category, difficulty, duration, passing percentage -> Save (a draft).
2. **Add question**: question text, four different options, select the circle of the correct one, marks, difficulty, optional explanation.
3. After at least 3 questions press **Submit for approval**. The quiz is locked while it is reviewed.
4. If it is rejected, read the reason, fix it and submit again. When approved it is visible to participants.
5. **View results** (approved quizzes): attempts, average, highest, lowest, pass rate and participant feedback.

## Participant
1. Register, log in. The dashboard shows your statistics and a suggested difficulty.
2. **Browse quizzes**: search or filter, open a quiz, press **Start quiz**.
3. Choose answers. The timer counts down; at 00:00 the quiz is submitted automatically. Or press **Submit quiz**.
4. The result page shows your score, grade, pass/fail, correct answers and explanations. Rate the quiz at the bottom.
5. **My attempts** shows your history; **Leaderboard** shows the ranking.
6. If you leave a quiz unfinished you can **Resume** it, but the clock keeps running.
